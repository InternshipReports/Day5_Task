# Day5_Task

## Titanic Survival Data Analysis
  # Project Overview
    -This project involves exploratory data analysis on the Titanic dataset using Python libraries like Pandas, Seaborn, and Matplotlib. The goal is to uncover patterns and insights related to passenger survival 
     based on features such as gender, class, age, and fare.

  # Dataset
   -The dataset used in this project was sourced from Data Science Dojo’s Titanic dataset on GitHub. It includes information such as:

     -Passenger ID, Name, Sex, Age
     -Passenger class (Pclass)
     -Fare paid
     -Survival status
     -Family connections (SibSp, Parch)
     -Embarkation point

  # Libraries Used
     -Pandas
     -Seaborn
     -Matplotlib

  # Key Steps Performed
     -Loaded and explored dataset structure (df.info(), df.describe())
     -Checked for missing values and value distributions
     -Created visualizations: histograms, countplots, boxplots, pairplots, and heatmaps
     -Explored correlation among numerical features
     -Analyzed survival based on class, gender, age, and fare

  # Key Visualizations
     -Age Distribution: Majority passengers were between 20–40 years
     -Survival Count by Gender and Class
     -Boxplot of Age vs Class
     -Correlation Heatmap and Pairplots
     -Survival Rate by Gender

  # Summary of Findings
     -Most passengers were male and belonged to 3rd class.
     -Females had a higher survival rate than males.
     -Younger passengers had slightly better survival chances.
     -Higher fare and 1st class were positively associated with survival.

  # Conclusion
     -The analysis highlights how socio-economic status and gender played a significant role in survival during the Titanic disaster. This project demonstrates the value of exploratory data analysis in 
      understanding real-world datasets.
